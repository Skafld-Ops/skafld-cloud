Recommendations

Critical: Resolve v33/v34 version mismatch

version.php says v34.0.0 dev but Dockerfile uses nextcloud:33-apache. This was the subject of 7+ fix commits over April 20-22. Decision needed: stay on v33 stable (safe) or plan v34 upgrade (when base image is available).

Warning: Verify S3 object storage is provisioned

Without S3, files are stored in the container volume and may be lost on redeployment. Verify the Railway bucket is provisioned and test uploads.

Warning: Update README.md

The README is stock Nextcloud. Add a Skafld Cloud header, deployment architecture, and links to cloud.skafldstudio.com at the top.

Suggestion: Create baseline release tag

Run git tag -a v0.1.0 -m "Baseline: Nextcloud 33 on Railway with Redis, Resend, Doppler" to anchor future changelogs.

Suggestion: Document upstream sync strategy

The upstream remote points to nextcloud/server. Document when and how to merge upstream changes (security patches, minor releases) while preserving the docker/ customizations.
